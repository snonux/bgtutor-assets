# Cartoon videos of the sample-test reading texts

Each official sample test (in [official-samples/](../official-samples/), described in
[official-materials.md](../official-materials.md))
opens with a short prose text and five questions about it. These cartoons act
out each text scene by scene: the narration reads the exam's own Bulgarian
text, sentence by sentence, and the same words appear as captions, so you can
hear, read and see the story at once.

| Video | Reading text | Length |
|---|---|---|
| [variant-1-burgas.mp4](variant-1-burgas.mp4) | Бургас, „най-добрият град за живеене в България" 2012 | 2:10 |
| [variant-2-levski.mp4](variant-2-levski.mp4) | Васил Левски, Апостола на свободата | 2:27 |
| [variant-3-teteven.mp4](variant-3-teteven.mp4) | Тетевен, най-зеленият град на България | 2:15 |

Every video has a matching `.srt` file with the captions, which a player such
as VLC can show as subtitles.

**How to use them:** watch the video once with captions, once without, then
answer questions 1–5 of that sample test. The voice spells out abbreviations
(„2012 г." is read „2012 година", „120 км" as „120 километра"). Two small
departures from the printed text: variant 1 reads out only the top three rows
of its ranking table (all seven are on screen), and variant 2's caption fixes
the printed typo „бъдещето въстание" to „бъдещото въстание".

## Live listening drills through MCP

In citizenship mode the tutor retrieves one subtitle cue at a time, with its
time range and matching video path. Watch or listen, then summarise, answer a
comprehension question or explain an unfamiliar expression. The AI waits for
your response and adapts; it can also read the caption aloud when you are not
watching the video. Afterwards answer the printed sample's questions 1–5,
using its complete passage and table. Captions are adaptations, not replacements
for the official test wording. Section progress resumes these drills later.

## How they were made

Everything is generated by the code in [src/](src/): the scenes are drawn
with Cairo, the narration is Microsoft Edge's Bulgarian neural voices
(Калина and Борислав) through the `edge-tts` package, and ffmpeg encodes the
result at 1280×720.

```sh
python3 -m pip install pycairo edge-tts
cd src
python3 make.py              # all three videos into ../
python3 make.py 2            # only variant 2
python3 make.py --stills 3 /tmp   # one PNG per scene, no audio (fast preview)
```

`edge-tts` needs network access. Behind a TLS-intercepting proxy, set
`SSL_CERT_FILE` to the proxy's CA bundle. To change a story, edit the
narration line or the draw function of a scene in `story1.py`–`story3.py`.
