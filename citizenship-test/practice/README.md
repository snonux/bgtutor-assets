# Practice tests

Three original tests in the exact layout of the official exam: 20 questions,
four options, one correct, 60 minutes, pass with 12. They were written for this
repository; the reading texts and their facts are invented for practice, so
don't quote them as real news.

| Test | Reading text |
|---|---|
| [test-01.md](test-01.md) | A town library opens on Sundays |
| [test-02.md](test-02.md) | A new eco trail in the Rhodopes |
| [test-03.md](test-03.md) | New public transport fares, with a table |

How to use them:

1. Set a 60-minute timer and write your answers on paper (А, Б, В or Г).
2. Only then open the answer key at the bottom of the file.
3. For each mistake, read the explanation and the linked study file, and add
   the word or rule to your flashcards.

Do these after the study lists, and keep the official samples
([official-materials.md](../official-materials.md)) for the last week. Aim for
17 or more before booking the exam, since the real paper is reported to be
harder than the samples.
